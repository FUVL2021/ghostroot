# Payload 目录说明

本目录存放 APK 打包时会被原样复制到 `lib/arm64-v8a/` 的二进制。

## libfuxi8550.so

| 项 | 值 |
|---|---|
| 来源 | **御坂114514 发布** |
| 设备支持 | **所有搭载小米 8550（SM8550）处理器的设备** |
| 大小 | 1,889,584 字节 |
| MD5 | `142355ab39b9205f2cb673afd430fa3c` |
| 类型 | 静态 ELF aarch64（可执行镜像，`.so` 仅为命名习惯，不作为动态库加载） |

声明支持机型（SM8550 平台）：小米 13 (fuxi) / 小米 13 Pro / 小米 13 Ultra /
Redmi K60 Pro / 小米平板 6 / 6 Pro / MIX Fold 3 等。
实际可用性仍取决于各自 ROM 与 kernel 版本。

> ⚠️ 该 payload 内含**硬编码内核符号偏移**，只对**相同 ROM / 相同 kernel 版本**有效。
> 换 ROM / 换系统版本后可能需要按目标机真实 `kallsyms` 调整；
> 不匹配时轻则无效，重则触发内核崩溃（RCU stall → 整机锁死，需长按电源重启）。

本项目仅**原样收录**该文件用于研究复现，版权与解释权归原作者所有。
